# BPMN-моделі «ШопЛайн» — спринт 1

Продукт: «ШопЛайн» · Спринт 1 · Дата: 23.09.2026 · Автор: Гаєвський Артем (Інженер з тестування) · Рецензент: Пінчук Катерина

## Інструмент

Нотація BPMN 2.0, формат `.bpmn` (XML). Редактор — bpmn.io (бібліотека bpmn-js 17). Файли також відкриваються в Camunda Modeler.

## Як відкрити

1. Відкрийте https://demo.bpmn.io.
2. Перетягніть `.bpmn`-файл у вікно браузера (або «Open» у лівому нижньому куті).
3. Згорнуті підпроцеси («Укомплектувати замовлення», «Повернути кошти покупцю») мають власну діаграму: натисніть на значок стрілки в правому нижньому куті підпроцесу.
4. Експорт: кнопка «Download» → SVG, для PDF — надрукувати SVG із браузера у файл.
